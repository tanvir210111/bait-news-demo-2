# সংবাদ ৭১ - অনলাইন নিউজ পোর্টাল (Static Website for Vercel)

এই প্রকল্পটি পিএইচপি/লারাভেল ডাটাবেজ ব্যাকএন্ড থেকে একটি দ্রুতগতির, আধুনিক এবং পূর্ণাঙ্গ স্ট্যাটিক ওয়েবসাইটে রূপান্তরিত করা হয়েছে যাতে সরাসরি **Vercel** এ কোনো পিএইচপি বা মাইএসকিউএল সার্ভার ছাড়াই শতভাগ কার্যকরীভাবে লাইভ করা যায়।

---

## 🌟 প্রধান বৈশিষ্ট্যসমূহ:
1. **১০০% স্ট্যাটিক ও ভার্সেল (Vercel) উপযোগী:**
   - সম্পূর্ণ পিএইচপি ও মাইএসকিউএল নির্ভরতা মুক্ত।
   - সব ৯৮টি খবরের পূর্ণাঙ্গ প্রতিবেদন, ক্যাটাগরি, ফটো ও ভিডিও গ্যালারি সরাসরি স্ট্যাটিক এইচটিএমএল হিসেবে প্রি-রেন্ডার করা।
   - `vercel.json` কনফিগারেশন যুক্ত করা রয়েছে (Clean URLs, routing rewrites, assets cache)।

2. **লাইভ ইন্টারেক্টিভ ফিচারস:**
   - **রিয়েল-টাইম অনুসন্ধান (Instant Live Search):** খবরের শিরোনাম বা বিষয়ের উপর ইনস্ট্যান্ট সার্চ।
   - **অনলাইন মতামত ও ভোট (Live Poll):** মতামত প্রদান, রিয়েল-টাইম পারসেন্টেজ বার অ্যানিমেশন এবং LocalStorage এ ভোট সংরক্ষণ।
   - **বাংলা ও ইংরেজি লাইভ ঘড়ি ও ক্যালেন্ডার:** স্বয়ংক্রিয়ভাবে আজকের বাংলা ও ইংরেজি তারিখ এবং সময় আপডেট।
   - **ব্রেকিং নিউজ ও স্ক্রলিং শিরোনাম:** মাউস রাখলে স্বয়ংক্রিয়ভাবে থেমে যাওয়া নিউজ স্ক্রলার।
   - **ফটো গ্যালারি ও ভিডিও প্লেয়ার:** সব ফটো অ্যালবাম ও ভিডিও প্রতিবেদনের লাইটবক্স প্রিভিউ।
   - **মন্তব্য ব্যবস্থা (Comments System):** প্রতিটি সংবাদে পাঠকদের মন্তব্য প্রকাশ ও প্রদর্শনের ব্যবস্থা।
   - **সোশাল শেয়ারিং:** ফেসবুক, টুইটার, হোয়াটসঅ্যাপ ও লিংক কপি বাটন।

## 🚀 লোকালহোস্টে চালু করার নিয়ম (Run on Localhost):

টার্মিনালে নিচের যেকোনো একটি কমান্ড দিলেই লোকালহোস্টে লাইভ চালু হবে:

```bash
# অপশন ১ (Node.js):
npm start
# অথবা
npx serve . -l 3000
```

বা পাইথন দিয়ে চালু করতে চাইলে:
```bash
python -m http.server 3000
```

এরপর ব্রাউজারে যান:
👉 **http://localhost:3000**

## 🌐 ভার্সেলে (Vercel) লাইভ করার নিয়ম (Deploy to Vercel):

### পদ্ধতি ১: GitHub / GitLab / Bitbucket
1. এই ফোল্ডারের ফাইলগুলো আপনার গিটহাবে পুশ করুন।
2. [Vercel Dashboard](https://vercel.com/new) এ যান।
3. আপনার রিপোজিটরিটি ইমপোর্ট করে **Deploy** বাটনে ক্লিক করুন। আর কোনো কনফিগারেশন লাগবে না, স্বয়ংক্রিয়ভাবে লাইভ হয়ে যাবে!

### পদ্ধতি ২: Vercel CLI দিয়ে এক কমান্ডে লাইভ
```bash
npx vercel --prod
```
ব্যাস! কয়েক সেকেন্ডেই আপনার সাইটটি লাইভ হয়ে যাবে।
